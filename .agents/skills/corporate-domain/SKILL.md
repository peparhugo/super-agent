# Corporate Domain Skill

## When to use
- Enterprise program management, compliance audits, and stakeholder-ready deliverables.
- Any workflow requiring audit trails, risk assessments, or governance sign-off.

## Workflow
1. Confirm business objectives, stakeholders, and success metrics.
2. Enumerate compliance and risk constraints (security, legal, privacy).
3. Produce a release plan with acceptance criteria and rollback steps.
4. Summarize results in executive-friendly language.

## Progressive disclosure
- If compliance or security requirements are complex, review `references/qa_checklist.md`.
- If you need reusable checklists, add them under `references/` instead of the main skill file.
