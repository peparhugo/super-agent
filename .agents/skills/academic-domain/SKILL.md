# Academic Domain Skill

## When to use
- Literature reviews, benchmark planning, reproducibility audits, or research methodology.
- Preparing experiment protocols or data provenance summaries.

## Workflow
1. Identify research goals, hypotheses, and evaluation metrics.
2. Gather sources and record citations and dataset licenses.
3. Define experimental setup, baselines, and reproducibility steps.
4. Summarize findings with limitations and future work.

## Progressive disclosure
- For citation integrity and dataset provenance, consult `references/reproducibility_guidelines.md`.
- Add datasets and bibliographies under `references/` rather than the main skill file.
